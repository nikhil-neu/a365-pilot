# a365-toolkit — executive brief

Preparing the security services that support Agent 365.

Give administrators a controlled way to deploy, configure and verify supporting security services, with explicit approval and evidence at each stage.

| Service | Capability | Delivery |
| --- | --- | --- |
| Entra | Agent Conditional Access, scoped rollout and control verification. | Narrow CA workflow |
| Defender | Security integrations, connector readiness and agent visibility. | Partial automation |
| Purview | Audit enablement and scoped data loss prevention policies. | Audit + DLP simulation |
| Sentinel | Ingestion, hunting, detections, workbooks and response preparation. | Starter deployment pack |

## Administrator control

Select the tenant and scope. Review existing settings and proposed changes. Approve the exact plan, deploy supported components, and verify configuration and runtime results. Approve enforcement separately.

## Delivery approach

Qualify workflows in development and sandbox tenants before production rollout. Expand service coverage and consolidate planning, execution, recovery and drift review into one administrator experience.

Available today: service-specific executors and a shared command entry point. Planned: cross-service orchestration, broader coverage and production qualification.
